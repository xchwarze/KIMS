> [!NOTE]
> ## KIMS has a successor: GIMS 4
>
> KIMS lived through two eras and taught a lot. **GIMS** is the next step: a complete rewrite, built around
> the same idea (many antivirus scanners, one window) but modern, fast and easy to extend.
>
> **Built for infrastructure.** GIMS is designed as a framework for building scanning services and
> distributed scanners, the kind of thing VirusTotal does: many engines behind one core, driven from a GUI
> or a command line, with every engine defined as plain text.
>
> - **A real Windows app**: drop a file on the window and read every scanner's verdict side by side.
> - **Engines are plain text**: add any command-line scanner by writing a small INI file. No code, no rebuild.
> - **Profiles, timeouts, cancel, download/update scripts**: everything KIMS users wished it had.
> - **Light and dark themes**, single-file portable folder, no installer, nothing written to the registry.
>
> ### 👉 Try it: [**GIMS Lite**](https://github.com/xchwarze/gims-lite)
>
> A GUI-only edition to try it out. The full version, with the command line, the source and the tooling for
> large setups such as your own VirusTotal-style service, is private.


KIMS
====

KIMS was the first local and web multi scan of the world which last version came out on 2006 
programed by Thor. In 2009 it began being developed to the new version by DSR!.
